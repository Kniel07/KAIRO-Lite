# KAIRO-Lite
## Architecture Decision Record (ADR) Index

Status: Index only — no ADRs recorded yet.

This is a placeholder, created as part of the Architecture Freeze governance checkpoint (Document 13 §22, Amendment Ledger). It exists to give the constitution a clean evolution path once real implementation work in Phase 4+ surfaces genuine architectural limitations, without bloating Documents 1–13 themselves or requiring every future decision to become a formal amendment.

### How this differs from Document 13 (Architecture Amendments)

Document 13 is the constitutional amendment ledger — every entry there changes or clarifies the ratified constitution (Documents 1–13) and is binding. An ADR here is a smaller-grained record of a single implementation-level decision (a library choice, a specific mechanism, a trade-off within an already-frozen pattern) that doesn't rise to the level of a constitutional amendment on its own. Not every ADR becomes an amendment; but a constitutional amendment that needs deeper technical justification than fits in Document 13's format may reference an ADR here for the detail.

### When to add one

Only when Phase 4+ implementation reveals a concrete decision worth recording — not proactively, and not to pre-populate coverage for hypothetical future choices. Per the Architecture Freeze review: no new governance artifacts unless they solve a concrete problem.

### Format, once ADRs exist

Sequentially numbered, one file per decision: `docs/adr/0001-short-title.md`, `docs/adr/0002-short-title.md`, etc. Each entry indexed here by number, title, and status (Proposed / Accepted / Superseded).
